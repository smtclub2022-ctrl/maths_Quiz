कक्षा 10 गणित — महत्वपूर्ण सूत्र बोर्ड परीक्षा त्वरित रिवीजन सारणी

अध्याय 1: वास्तविक संख्याएँ

  • यूक्लिड विभाजन प्रमेय: a = bq + r जहाँ 0 ≤ r < b
  • दो संख्याओं का संबंध: HCF(a, b) × LCM(a, b) = a × b

अध्याय 2: बहुपद

  • द्विघात बहुपद ax² + bx + c = 0 के शून्यक α व β हों तो:
  • शून्यकों का योग: α + β = -b / a
  • शून्यकों का गुणनफल: α × β = c / a
  • द्विघात बहुपद: k[x² - (α + β)x + αβ]

अध्याय 3: दो चरों वाले रैखिक समीकरण युग्म

  • a₁/a₂ ≠ b₁/b₂ ➔ अद्वितीय हल (प्रतिच्छेदी रेखाएँ, संगत)
  • a₁/a₂ = b₁/b₂ = c₁/c₂ ➔ अनंत अनेक हल (संपाती रेखाएँ, आश्रित/संगत)
  • a₁/a₂ = b₁/b₂ ≠ c₁/c₂ ➔ कोई हल नहीं (समांतर रेखाएँ, असंगत)

अध्याय 4: द्विघात समीकरण

  • विविक्तकर (Discriminant): D = b² - 4ac
  • D > 0 ➔ दो भिन्न वास्तविक मूल
  • D = 0 ➔ दो बराबर वास्तविक मूल (x = -b / 2a)
  • D < 0 ➔ कोई वास्तविक मूल नहीं
  • द्विघाती सूत्र (श्रीधराचार्य): x = (-b ± √D) / 2a

अध्याय 5: समांतर श्रेढ़ी (AP)

  • nवाँ पद: aₙ = a + (n - 1)d
  • प्रथम n पदों का योग: Sₙ = (n/2)[2a + (n - 1)d] अथवा Sₙ = (n/2)(a + l)

अध्याय 8: त्रिकोणमितीय अनुपात

  • sin θ = लम्ब / कर्ण, cos θ = आधार / कर्ण, tan θ = लम्ब / आधार
  • cot θ = 1 / tan θ, sec θ = 1 / cos θ, cosec θ = 1 / sin θ

प्रमुख त्रिकोणमितीय सर्वसमिकाएँ

  • sin² θ + cos² θ = 1 ➔ sin² θ = 1 - cos² θ, cos² θ = 1 - sin² θ
  • 1 + tan² θ = sec² θ ➔ sec² θ - tan² θ = 1
  • 1 + cot² θ = cosec² θ ➔ cosec² θ - cot² θ = 1

अध्याय 9: ऊँचाई और दूरी

  • उन्नयन कोण (Angle of Elevation): जब वस्तु क्षैतिज स्तर से ऊपर हो।
  • अवनमन कोण (Angle of Depression): जब वस्तु क्षैतिज स्तर से नीचे हो।
  • tan θ = ऊँचाई / क्षैतिज दूरी

अध्याय 6: त्रिभुज

  • थेल्स प्रमेय (BPT): यदि DE ∥ BC हो, तो AD/DB = AE/EC
  • पाइथागोरस प्रमेय: समकोण त्रिभुज में (कर्ण)² = (लम्ब)² + (आधार)²

अध्याय 7: निर्देशांक ज्यामिति

  • दूरी सूत्र: d = √[(x₂ - x₁)² + (y₂ - y₁)²]
  • मूल बिंदु से दूरी: d = √(x² + y²)
  • विभाजन सूत्र (m₁:m₂): x = (m₁x₂ + m₂x₁) / (m₁ + m₂), y = (m₁y₂ + m₂y₁) / (m₁ + m₂)
  • मध्य-बिंदु सूत्र: ((x₁ + x₂)/2, (y₁ + y₂)/2)

अध्याय 10: वृत्त

  • स्पर्श रेखा स्पर्श बिंदु से जाने वाली त्रिज्या पर लम्ब होती है (90°)।
  • बाह्य बिंदु से वृत्त पर खींची गई स्पर्श रेखाओं की लम्बाइयाँ समान होती हैं (PA = PB)।

अध्याय 12: वृत्तों से संबंधित क्षेत्रफल

  • वृत्त का क्षेत्रफल: πr² | परिधि: 2πr
  • त्रिज्यखंड का क्षेत्रफल: (θ / 360°) × πr²
  • चाप की लंबाई: (θ / 360°) × 2πr

अध्याय 13: पृष्ठीय क्षेत्रफल और आयतन

  • बेलन: वक्र पृष्ठ = 2πrh | कुल पृष्ठ = 2πr(r + h) | आयतन = πr²h
  • शंकु: तिर्यक ऊँचाई l = √(r² + h²) | वक्र पृष्ठ = πrl | आयतन = (1/3)πr²h
  • गोला: पृष्ठीय क्षेत्रफल = 4πr² | आयतन = (4/3)πr³
  • अर्धगोला: वक्र पृष्ठ = 2πr² | कुल पृष्ठ = 3πr² | आयतन = (2/3)πr³

अध्याय 14: सांख्यिकी

  • प्रत्यक्ष विधि से माध्य: x̄ = Σ(fᵢxᵢ) / Σfᵢ
  • कल्पित माध्य विधि: x̄ = a + [Σ(fᵢdᵢ) / Σfᵢ]
  • बहुलक, माध्यिका व माध्य में आनुभविक संबंध: 3 × माध्यक = बहुलक + 2 × माध्य

अध्याय 15: प्रायिकता

  • प्रायिकता सूत्र: P(E) = अनुकूल परिणामों की संख्या / कुल परिणामों की संख्या
  • 0 ≤ P(E) ≤ 1
  • पूरक घटना: P(E) + P(not E) = 1 ➔ P(not E) = 1 - P(E)
